---
name: Grain visual palette
description: The enduring color direction for the Grain Marketplace product
---

Grain Marketplace uses a modern luxury palette built from coal, graphite, platinum, and cool slate tones. Warm coffee browns, amber, yellow, and orange should not be used as general brand accents in Grain.

**Why:** Grain needs a distinct visual identity from Coffee Marketplace while retaining the same agricultural product family.

**How to apply:** Use the existing cool neutral design tokens for surfaces, navigation, controls, charts, auth accents, badges, onboarding, and dashboard status treatments. Keep green, blue, and red only where they communicate semantic success, informational, or error states.
